# Уведомления в приложении покупателя (Firebase) — настройка один раз

Что приходит покупателю: смена статуса заказа («принят в работу», «отправлен», «доставлен»), ответ продавца в чате по товару,
ход возврата, поступление в пункт выдачи и другие уведомления покупателя, которые создаёт сайт. Работает и когда приложение закрыто.

## 1. Проект Firebase (бесплатно)
1. Откройте https://console.firebase.google.com, войдите аккаунтом Google → **Создать проект** (имя любое, например `mahnet`; Google Analytics можно выключить).
2. В проекте: значок **Android** («Добавить приложение») → имя пакета строго **`ru.mahnet.buyer`** → «Зарегистрировать» → **Скачать google-services.json**.
3. Дальше «Далее» до конца (проверку подключения пропустите).

## 2. Файл google-services.json в проект приложения
Положите скачанный файл в папку **`app/`** проекта на GitHub (рядом с `build.gradle` внутри `app`, путь `app/google-services.json`) и пересоберите приложение.
Без этого файла приложение собирается и работает, но уведомлений не будет.

## 3. Ключ для сайта (файл сервисного аккаунта)
1. В Firebase: ⚙ **Настройки проекта** → вкладка **Сервисные аккаунты** → **Создать новый закрытый ключ** → скачается `.json`.
2. Откройте этот файл блокнотом, скопируйте **весь** текст.
3. В админке сайта: вкладка **«Push-уведомления»** → вставьте текст в поле → **Сохранить ключ**.
4. Установите приложение на телефон, откройте его, разрешите уведомления. В админке нажмите **«Тест всем устройствам»** — на телефон придёт «Тест: уведомления работают».

Файл ключа нельзя никому отправлять: с ним можно слать уведомления от имени вашего проекта. Он хранится на хостинге в закрытой папке `push_store/`.

## Если не пришло
- Вкладка «Push-уведомления» показывает «Устройств: 0» → приложение не передало код: откройте приложение, подождите полминуты, проверьте, что разрешили уведомления и что `google-services.json` был в проекте при сборке.
- Ошибка при тесте → текст ошибки показан там же; пришлите её.
- На телефонах Xiaomi/Huawei/Samsung разрешите приложению работу в фоне и автозапуск (в настройках батареи).
